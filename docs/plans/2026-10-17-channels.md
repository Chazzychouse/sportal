# Channels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a Display watch any sports channel, such as ESPN during College GameDay, from a Channels entry in the guide, on a tile of its own.

**Architecture:** `Guide#lineup` in the domain picks a guide's sports channels with their airing now and next. The Hub's `Source` port gives it from each source, and a `lineup` RPC answers it. The web asks for the lineup every minute once Channels has shown, lists it as channel guide items, and Enter places a new `ChannelTile` through a new `AssignChannel` screen command.

**Tech Stack:** TypeScript 7, Effect 4 (`Schema`, `Context.Service`, `effect/rpc`, `effect/reactivity` atoms), React, Vitest via `@effect/vitest`.

**Spec:** `docs/specs/2026-10-17-channels-design.md`. **Spec amendment (decided 2026-10-17 with the user):** some local stations are named for their call sign, not their network ("News 3" is CBS, "WAVY 10" is NBC). They join the lineup through a Hub setting, `SPORTAL_LINEUP_CHANNELS` (comma-separated channel names, default none), read as `HubConfig.lineupChannels`. The sports-network list also gains the names the recorded guide uses: BTN, NBCSN, TBS, TNT, truTV, USA.

const OnAir = Schema.Struct({
  title: Schema.String,
  begin: Schema.DateTimeUtcFromString,
  end: Schema.DateTimeUtcFromString
})

/**
 * A source's sports channels that play live, in its guide's order, each with the airing on it now and the next to
 * begin; given by `Guide#lineup`.
 */
export const Lineup = Schema.Array(
  Schema.Struct({
    channel: Channel,
    now: Schema.OptionFromOptionalKey(OnAir),
    next: Schema.OptionFromOptionalKey(OnAir)
  })
)
export type Lineup = typeof Lineup.Type

3. In the class, after `availabilityOf` (before the private `from`), add:

```ts
  /**
   * This guide's sports channels that play live, in its order, each with the airing on at `now` and the earliest to
   * begin after it. A sports channel is one network's stream, one whose name names a sports network ("ABC 13" for
   * ABC), or one `alsoNamed` names (a local station named for its call sign, as "News 3"), read without case or
   * punctuation.
   */
  lineup(now: DateTime.Utc, alsoNamed: ReadonlyArray<string>): Lineup {
    const named = new Set(alsoNamed.map(normalized))
    return this.channels.flatMap(({ id, name, live, network }) => {
      const sports =
        network !== undefined ||
        named.has(normalized(name)) ||
        sportsNetworks.some((sportsNetwork) => namesNetwork(name, sportsNetwork))
      if (live === undefined || !sports) return []

      const airings = this.airings.filter(({ channel }) => channel === id)
      const onNow = Arr.findFirst(airings, ({ begin, end }) =>
        DateTime.isLessThanOrEqualTo(begin, now) && DateTime.isLessThan(now, end)
      )
      const later = airings.filter(({ begin }) => DateTime.isGreaterThan(begin, now))
      const next = Arr.head(Arr.sortWith(later, ({ begin }) => begin, DateTime.Order))
      const channel = { name, source: this.source, locator: live }
      return [{ channel, now: Option.map(onNow, onAir), next: Option.map(next, onAir) }]
    })
  }
```

import { Atom } from "effect/reactivity"

/** One asking of the lineup, retried every minute until it succeeds. */
const askLineup = Effect.gen(function* () {
  const hub = yield* HubClient
  return yield* hub.lineup
}).pipe(Effect.retry(Schedule.spaced(Duration.minutes(1))))
